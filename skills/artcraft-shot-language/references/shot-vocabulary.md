# 镜头语言速查词表（景别 · 机位 · 运动 · 构图 · 光线）

> 本表是 `../SKILL.md` 的紧凑查表版：每行 = 术语 → 叙事功能 → 何时用 → 何时别用 → 家族落点。
> 家族落点命令见 `artcraft-ops/references/command-families.md`；运镜实现在 EffectCraft `camera.*` / `view.3d.*`。

## 一、景别（8 级）

| 术语 | 英文 | 叙事功能 | 何时用 | 何时别用 |
|---|---|---|---|---|
| 大远景 | ELS | 环境即主题、人的渺小 | 开场、段落转场、孤独 | 对话戏、细节 |
| 远景 | LS | 空间关系、群像 | 建立镜头、调度展示 | 情绪刻画 |
| 全景 | FS | 全身动作完整 | 动作段落、舞蹈 | 内心戏 |
| 中景 | MS | 对话主力 | 常规对话、信息交换 | 强调细节 |
| 中近景 | MCU | 情绪进入 | 对话升级、微表情 | 大动作 |
| 近景 | CU | 情绪、心理 | 情绪峰值、关键台词 | 交代空间 |
| 大特写 | ECU | 压迫、符号 | 反转、道具暗示 | 长段落 |
| 插入特写 | INSERT | 强调物件/手部 | 细节交代 | 无信息量时 |

**节奏规则**：相邻镜头避免同景别硬接；情绪上升递进（MS→MCU→CU）；段落收束回 LS。

## 二、机位与角度（9 种）

| 角度 | 心理效果 | 何时用 |
|---|---|---|
| 平视 | 平等、客观 | 常态对话（基准） |
| 仰拍 | 权威、压迫、英雄化 | 强者、威胁、宣言 |
| 俯拍 | 弱势、被审视 | 失败、屈服、俯瞰调度 |
| 鸟瞰/上帝视角 | 命运感、宿命 | 开场/结尾、宏观 |
| 虫视 | 极端压迫 | 强对比、类型化 |
| 斜角 Dutch | 失衡、不安 | 危机、精神异常 |
| 过肩 OTS | 关系、代入 | 正反打对话 |
| 主观 POV | 强代入 | 惊悚、视角绑定 |
| 反打 reverse | 对话闭环 | 正反打配对 |

**轴线**：保持 180°；越轴用中性镜头或运动越轴过渡。**在调度图阶段标出轴线**（FigCraft/DeckCraft 画俯视图）。

## 三、运动（12 种）

| 运动 | 语义 | 何时用 | 何时别用 |
|---|---|---|---|
| 推 in | 进入、聚焦、压迫 | 强调、揭示 | 每镜都推=廉价 |
| 拉 out | 抽离、揭示环境 | 段落收尾、反转 | 情绪正高时 |
| 摇 pan | 展示空间、跟随 | 环境交代、横向转移 | 快速摇易糊 |
| 移 track | 伴随、沉浸 | 走廊、跟随人物 | 无动机时 |
| 升降 crane | 宏大、命运 | 开场/结尾 | 小场景 |
| 跟 follow | 参与感 | 动作、行走 | 无稳定器时 |
| 手持 | 真实、紧张 | 纪实、冲突 | 精致产品镜头 |
| 环绕 orbit | 仪式感、审视 | 英雄时刻、产品 | 对话戏 |
| 甩 whip pan | 突发、连接 | 转场、惊喜 | 频繁使用 |
| 变焦 zoom | 机械抽离/惊觉 | 强调突变 | 与位移混用（晕） |
| 位移 dolly | 观众移动/进入 | 沉浸、揭示 | 无动机时 |
| 静态固定 | 稳定、观察 | 对话、构图展示 | 长段落无变化（闷） |

**单镜单向**：一个镜头一个运动方向；起幅与落幅要有"到达感"；缓动（`keys.easyEase*`）是默认。

## 四、构图（12 条）

| 法则 | 用途 | 落点 |
|---|---|---|
| 三分法 | 通用平衡 | FigCraft `grid.*` / VectorCraft `view.guides.*` |
| 中心构图 | 仪式、对峙 | FilmCraft `graphics.alignFrame.hcenter/vcenter` |
| 对称 | 秩序/压迫 | 精确对齐（同上） |
| 框式 | 窥视、层次 | 前景元素（`graphics.arrangeLayer`） |
| 引导线 | 视线导向 | VectorCraft `perspective.grid/snap` |
| 负空间 | 孤独、留白 | 主体偏移（`graphics.nudge*`） |
| 视线空间 | 看向方向留空 | 主体偏左留右 |
| 头顶空间 | 挤压/漂浮感 | `graphics.nudgeUp/Down` |
| 前景/中景/远景 | 纵深 | EffectCraft 分层合成 |
| 重复与韵律 | 秩序美感 | 符号/组件复用（VectorCraft `symbol.*`） |
| 打破对称 | 张力 | 斜角、偏心 |
| 明暗对比引导 | 视觉落点 | LightCraft `grading.*` / 光效层 |

## 五、光线（10 种）

| 光型 | 效果 | 何时用 | 落点 |
|---|---|---|---|
| 主光+辅光 | 常规立体 | 多数场景 | LightCraft `light.*` |
| 轮廓光 rim | 分离背景 | 暗背景人像 | `grading.highlights.*` |
| 伦勃朗光 | 戏剧肖像 | 人物特写 | `grading.*` 分区 |
| 明暗对照 | 强对比压迫 | 悬疑/权谋 | `light.contrast` + `curve.*` |
| 顺光/平光 | 干净、无阴影 | 商业、美妆 | 减对比 |
| 侧光 | 质感、立体 | 人物、产品 | `detail.sharpenAmount` 配合 |
| 逆光 | 氛围、剪影 | 情绪段落 | 高光处理 |
| 实用光 | 真实光源入画 | 夜戏、室内 | EffectCraft 光效层 |
| 黄金时刻 | 温暖、怀旧 | 情感段落 | `wb.temp/tint` + `grading` |
| 无源光 | **大忌**：光无来源 | —— | 调度图标注灯位即可避免 |

**光比**：写实 4:1–6:1；悬疑/惊悚 8:1 以上；喜剧/商业 2:1–3:1。

## 六、检查清单（分镜/拍摄前）

- [ ] 每镜有明确景别与角度，且相邻不重复
- [ ] 运动单镜单向，有起落幅
- [ ] 轴线一致（调度图画过）
- [ ] 主体有视线空间/头顶空间
- [ ] 光有来源（灯位已标）
- [ ] 情绪目标一句话能说清（见 artcraft-style-bible 命门句）
- [ ] 关键镜头有覆盖（主镜+插入+反应）
